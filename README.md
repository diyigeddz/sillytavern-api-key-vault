# API 密钥仓库 v0.3.0

为 SillyTavern 自定义 OpenAI 兼容接口制作的本地密钥仓库。一个渠道可以保存多把明文 Key，并可直接把渠道 URL 与所选 Key 填入酒馆连接配置。

## 功能

- 一个渠道保存多把 Key
- 渠道名称、URL、来源分类、模型标签与备注
- Key 明文显示；操作区可按需展开，支持复制、直接填入、编辑、失效标记与删除
- 月度刷新日期、有效期和到期提示
- 渠道整体失效、恢复及整组删除
- 每把 Key 独立读取额度：能识别就展示，不能读取就说明原因
- 渠道管理区折叠显示，长列表更紧凑
- 默认灰度调整为不刺眼的中间亮度，并保持文字清晰
- 右上角支持日间/夜间模式切换，并记住上次选择
- 搜索和状态筛选
- JSON 明文导入与导出备份
- 数据保存在当前浏览器 localStorage

## 安装

将压缩包解压后，把 `api-key-vault` 文件夹放入：

`SillyTavern/public/scripts/extensions/third-party/`

重新启动 SillyTavern 并刷新页面。进入“API 连接配置”，在“自定义 API 密钥”输入框旁点击 🔐 即可打开。

## 提醒

仓库和导出的 JSON 备份均包含完整明文 Key。清理浏览器数据或更换浏览器前请先导出备份，并妥善保管备份文件。
